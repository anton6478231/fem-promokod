# ФЭМ сайта промокодов

Интерактивная финансовая модель: открывается в браузере, без установки.

**Ссылка:** https://anton6478231.github.io/fem-promokod/

Первый запуск может занять 20–40 секунд — в браузер подгружается Python. Дальше страница открывается быстрее.

## Локальный запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется `http://localhost:8501`. Подробности — в `QUICKSTART.md`.
